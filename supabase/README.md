# 晨充网页版云端

独立项目已在用户指定的BallCard个人组织建立，迁移已应用。Supabase负责登录、私有RLS表、Vault加密与分钟级Cron；Vercel Node.js负责验证用户会话、预约接口与执行。当前固定入口为[晨充](https://neptune-charge-hub.vercel.app/)。

`migrations/` 文件由官方CLI 2.120.0生成，版本号与实际远程迁移历史对齐。私有表启用RLS并撤销公开客户端访问，仅供验证身份后的服务端接口使用；付款身份、冻结授权与原开电请求加密保存。客户端仅使用公开publishable key，服务端凭据托管在Vercel Production Secret。

事务化预约、提交前取消、执行租约、单次提交占用及原请求核对已接入。Supabase Edge与尼普顿HTTPS握手不兼容，因此实际入口使用Vercel Node.js，未关闭证书验证或通过HTTP发送付款身份。分钟任务与受保护回调已核对，旧电脑计划没有迁移或重复登记。

41项离线检查、27项实际云端接口检查与额外取消/提交竞争检查通过；真实付款链接已做只读核对，没有以此新建充电。手机真机操作和新版云端扣款开电仍未现场验收。详细架构与限制见[云端执行](../docs/cloud-execution.md)。

项目使用新加坡Free套餐；不升级或删除旧项目。管理登录和数据库密码由本人处理，密码不写入源码或日志。充电结果在网页记录查看，不发送邮件提醒；注册邮箱确认保留。
