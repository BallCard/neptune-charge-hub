# 扣子与国内托管平台核对

核对日期：2026-10-15。以当前Vercel正式版为业务基线，先用独立的公开设备测试项目核对扣子出网，不复制账号、付款身份、数据库密钥或预约记录。

## 官方能力与约束

- [项目导入](https://docs.coze.cn/coze-cli-import-existing-project)：支持GitHub与本地ZIP。已使用只有五个文件的Node.js只读查询包，本地启动、单设备读取、缓存及拒绝充电路由检查通过；本机通过不等于扣子通过。
- [网页部署](https://docs.coze.cn/guides_deploy_vibe_web)：支持动态网页、生产环境变量及默认coze.site域名；只支持公开部署。无流量时实例可缩容到零，不能用进程内计时器承载预约。
- [配额](https://docs.coze.cn/guides_vibe_coding_limit)：开发沙箱空闲一小时会断开，预览不能替代正式部署验收；HTTP空闲连接最多90秒。
- [托管计费](https://docs.coze.cn/coze_pro_service_hosting_fee)：访问时按算力与流量计费，每天结算。当前公布1CU为1核2GB，算力0.18积分/CU/秒、流量80积分/GiB；实际扣费、额度和订阅限制以账号页面为准。
- 已查到的“固定IP”文档描述调用扣子OpenAPI的入口，不能作为部署应用具有固定公网出口的证明。尼普顿连通性、出口稳定性、访问Supabase的能力必须单独实测。
