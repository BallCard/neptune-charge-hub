## Windows 兼容

原 `neptune_charge.py`、`failure_email.py`、`mail_worker.py`、`ui_server.py` 成为加载统一源码的薄入口，保留原 `__file__`，所以 DPAPI 账号、日志和预约路径仍指向原目录。原 PowerShell 入口传递 `RuntimeRoot`，同一任务的原脚本路径和参数继续可识别。没有登记、取消或运行任何充电任务，没有复制账号和通知凭据。

双击旧桌面入口/`open-ui.cmd` 或主项目 `open-hub.cmd` 打开 `http://127.0.0.1:3086/`。本机服务复用原只读界面后台，通过服务器内存中的会话值桥接原 reserve/cancel；浏览器另用本机会话、Host、Origin校验。公开部署没有这些 Windows 路由或会话。当前网页主流程面向云端，电脑旧预约在折叠卡片里只读查看。原电脑后台与任务保留，新云端计划不复制已有电脑计划。

完整主项目可独立克隆。若同级旧 Windows 目录不存在，本机入口使用 `native/windows/`，需重新配置该机器的账号；不从其他机器迁移 DPAPI 数据。

旧 Windows README 的历史使用细节与 CHANGELOG 保留；旧空位线上地址暂仍是此前发布版本，原独立 `api/status.py` 仅保留部署兼容。新版本发布前不删除旧目录或切换旧线上入口。旧空位 `monitor.py` 已转向统一源码，其旧静态面板仍能作为兼容页运行。

## 附近查询

唯一维护的站点清单为 `modules/nearby/stations_yuquan.csv`，保持上游 BD-09。构建生成浏览器使用的公开站点 JSON；高德导航转换为 GCJ-02，浏览器 WGS-84 定位转换后参与距离比较，百度仍用 BD-09。定位不上传、不持久化；点击导航时由地图接收目的地。

网页/本机入口调用同源 `/api/nearby`；Vercel 部署包只增加一个只读公开设备函数。安卓内置页不加载远程页面、不开放远程桥接，通过内置清单和专用 `nearbyStatus` 只读取 `getDeviceInfo`。部分设备失败时不计为可用孔位，保留错误和更新时间；页面折叠或在后台时暂停刷新。选择绿色孔位只填入目标，仍须官方核对和本人接好确认。
