## 个人云端执行

个人版魔搭承载网页、公开端口查询和受保护的Node.js执行接口；Supabase沿用登录、加密账号、预约记录和唯一每分钟调度。公开查询仅访问固定站点的getDeviceInfo，不读取账号、付款授权或预约，也不创建后台调度。尼普顿HTTPS与Supabase Edge握手不兼容，原Vercel线路也出现过超时，现已将执行端改至魔搭并完成公开设备读取。魔搭占用Authorization头，应用会话与调度使用独立X-Neptune-Session头，仍由原服务端验证身份与数据库防重，未降低HTTPS保护。详见[魔搭部署](docs/modelscope-assessment.md)与[云端执行](docs/cloud-execution.md)。

同一预约的新请求只发一次。丢失响应、超时或中断后核对原请求与本人订单；结果不明继续限制。提交前可取消并重新预约，取消与提交由数据库决定唯一结果；取消不会停止已开电订单。到点重新核对账号、插座与费用，晚到超过十分钟窗口便不执行。按用户要求不提供邮件提醒，结果在网页“记录”查看。
