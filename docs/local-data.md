# 本机数据与安卓 / iPhone 使用

用户已选择：个人数据留在本机；安卓先做手机网页及主屏幕入口，定时执行另行接入。

## 现在能做什么

在当前浏览器创建本机空间，密码至少8个字符。首次从微信复制付款页链接，网页仅在本机解析它；账号、插座、时间偏好、金额上限和计划一起加密写入 IndexedDB。网页不请求尼普顿、不向开发者网站上传这些值，也不注册邮箱。

计划状态只有“已保存、已取消、已过期”，没有已开电或定时执行已生效。默认北京时间06:00，可自行选择1分钟后到24小时内的日期时间；每次保存仍需确认车辆已接好。星期偏好只推荐日期。

安卓使用新版 Chrome 或兼容浏览器，在菜单中选择“安装应用 / 添加到主屏幕”；支持安装提示时，也可使用页面按钮。iPhone 使用 Safari 分享菜单的“添加到主屏幕”。建议先添加，再在主屏幕入口创建本机空间，避免浏览器与独立入口的存储差异。

离线缓存仅保存网页程序、样式和图标。第一次需要联网打开，缓存成功后可以离线打开、解锁和管理本机计划。不同浏览器的安装、存储和离线行为需要实际设备核验；目前尚无用户手机实测记录。

## 数据保护与转移

- 密钥由本机密码通过 PBKDF2-SHA256、310000轮计算得到，账号与设置使用 AES-256-GCM 加密。密码与密钥不持久保存；闲置5分钟后锁定。
- 写入采用 IndexedDB 事务比较版本和密文，多个页面并发操作时拒绝覆盖较新的数据。
- 在“偏好设置”导出加密备份；换设备或空浏览器空间时，输入原本机密码并选择备份恢复。文件读取和解密都在本机完成。
- “导出计划”不含账号授权，明确标记 `executable=false`，不能把它当作可直接开电的指令。
- 清除网站数据、浏览器卸载、系统回收存储或密码丢失可能使数据不可恢复。网站无法找回密码，需自己保留备份。
- 网站不做云同步；系统、浏览器及下载文件的备份行为由设备设置决定。严格本地需求应核对 iCloud、系统备份和所选文件位置。

## 定时执行边界

网页和主屏幕入口不能保证锁屏后准时执行网络操作，本版本没有网页计时器、后台重试或充电 API。旧的个人 Windows 工具仍可按原方式使用。

苹果快捷指令的只读验证见[操作步骤](./iphone-shortcuts-validation.md)。安卓后续需要独立的本地执行能力与定时权限、后台限制、断网及防重复提交验证；用户当前已将此项留待下一阶段。Android 官方说明了准确闹钟权限及省电限制：[Schedule alarms](https://developer.android.com/develop/background-work/services/alarms)。

## Vercel 边界

Vercel 只提供静态 HTML、JavaScript、样式和图标。源码没有登录服务、云数据库或服务端业务 API，没有分析上报和第三方资源；正常访问仍会产生托管平台的网页访问日志，但个人付款链接、密码和计划不进入请求 URL 或请求体。

旧云端原型保存在本机 Git 首个提交及被忽略的 `.local/cloud-prototype/`，不进入静态发布包。此前创建的云资源未删除，也不接收本版本的业务数据。
