# 晨充 · 找空位与充电预约

统一原手机前端、Windows充电工具与玉泉周边空位查询，以本项目作为后续开发主项目。用户已确定只用网页，不再构建或发布APK。

## 当前状态

手机单页、Antigravity/Gemini界面、常驻新手指引、微信付款链接教程和玉泉附近空位已整合并上线。**独立Supabase新库、Vercel预约接口和每分钟云端调度已接通；真实车辆与扣款尚需本人现场验收。**

新库使用用户指定的个人组织；旧Supabase项目和Windows已有预约保留。账号授权须本人手动导入，前端仅包含公开配置；没有将原电脑凭据上传或复制旧预约。

## 打开与使用

- 本地双击 `open-hub.cmd`，或原桌面入口，访问 `http://127.0.0.1:3086/`。电脑旧预约在折叠卡片里只读显示，任务与账号仍在原目录。
- 手机网址：[晨充](https://neptune-charge-hub.vercel.app/)。安卓与iPhone均直接使用网页，无需APK。
- 主屏一屏预约，底部导航为“晨充、找空位、记录、我的”。空位与记录在独立栏目内部滚动，底栏保持可见。
- “找空位”查看玉泉站点，支持搜索、距离排序、逐孔状态和地图导航。点绿色孔位填入编号并回到晨充，不会开电。
- 顶部“新手指引”和“我的”帮助入口随时重开；付款授权旁的问号也可查看完整复制链接教程。登录与预扣上限放在“我的”。

使用流程：登录晨充 → 网页选空闲口，或微信扫现场插座 → 按指引粘贴本人付款页链接 → 核对插座、真实套餐、时间和预扣金额 → 实际接好线并确认预约 → 查看“预约已生效”及结果。付款页与网页选中插座不同会明确要求选择；不再要求上传二维码或手动填写设备号。云端预约生效后无需电脑开机。

晨充账号与Supabase管理账号分开，首次需注册。当前默认确认邮件仅支持项目成员邮箱，首次请使用创建Supabase时的邮箱；面向其他用户开放前须配置自有邮件服务。没有关闭邮箱确认来绕过限制。

二维码仅提供设备与插座编号，不含付款身份。完整付款链接含本人授权，不能分享、写入源码或日志。旧电脑计划不自动迁移，也不能再登记成同一云端计划。

## 云端方案

Vercel承载网页、公开空位和受保护的Node.js执行接口；Supabase承载登录、加密账号、预约记录和每分钟调度。尼普顿HTTPS与Supabase Edge握手不兼容，改用Node.js后连接验证通过，未降低付款传输保护。详见[云端执行](docs/cloud-execution.md)。

同一预约的新请求只发一次。丢失响应、超时或中断后核对原请求与本人订单；结果不明继续限制。提交前可取消并重新预约，取消与提交由数据库决定唯一结果；取消不会停止已开电订单。到点重新核对账号、插座与费用，晚到超过十分钟窗口便不执行。按用户要求不提供邮件提醒，结果在网页“记录”查看。

npm test
npm run build
