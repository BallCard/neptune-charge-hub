# 晨充纯网页与云端执行

核对日期：2026-10-13。已在用户指定的个人组织建立独立 `neptune-charge-web` 库，并发布到 [晨充](https://neptune-charge-hub.vercel.app/)。这是个人测试版；真实车辆、实际扣款和订单仍需本人现场验收。

2026-10-14共享限流、保守容量准入、每轮两笔并行和调度故障汇总已发布。下文每轮一笔描述的是10月13日基线；当前验证与发布记录见[并发安全核验](security-capacity-review.md)。

## 已接通的组成

- Vercel：手机单页、公开玉泉空位函数、受保护的 Node.js 预约接口与执行器。
- Supabase：邮箱登录、会话校验、私有账号及预约表、Vault 加密与每分钟调度。
- 官方 Supabase CLI 已授权连接新项目。旧连接器账号和旧项目未用于新库，原 Windows 凭据与任务未迁移。

最初部署的 Supabase Edge 执行环境与尼普顿的 HTTPS 握手不兼容，日志确认 `HandshakeFailure`。执行接口改用 Vercel Node.js 后，当时公开设备读取通过；没有把付款身份降级为 HTTP 传输，也没有关闭证书验证。Supabase Cron 通过 Vault 中的独立调用凭据请求 Vercel 的受保护接口。10月15日复查发现Vercel到上游的连接仍会超时，东京切换也只暂时成功；预约后端的真实开电链路尚未验收。

公开 `/api/nearby` 已改用现有数据库的pg_net异步HTTPS出口，只能读取固定35台设备的 `getDeviceInfo`。所有访客共用30秒查询批次，内部表与RPC仅服务端可用，缓存只保留逐孔状态与坐标；返回实际读取时间，超过60秒停止返回可操作数据。此路径不处理付款身份、预约或开电，不能代替执行前的实时核对。

每分钟回调已启用；检查到连续 HTTP 200、无超时和新心跳。预约接口要求近期调度心跳，否则不登记。每轮最多处理一笔；可能延迟，超过预约后的十分钟执行窗口便停止新开电。云端记录已确认生效后，不需要电脑或网页保持打开。

## 使用

1. 注册并登录晨充账号。晨充账号与 Supabase 管理登录分开；当前默认邮件服务仅允许项目成员邮箱，首次建议使用创建 Supabase 项目时的邮箱。面向其他用户开放前需接入自有 SMTP，未通过关闭邮箱确认绕过限制。[官方邮件服务限制](https://supabase.com/docs/guides/auth/auth-smtp)。
2. 网页选空闲口，或用微信扫描现场插座；按指引复制本人付款页完整链接。
3. 粘贴后仅核对账号和真实套餐，再加密保存。无网页目标时使用付款页插座；两个目标不同则明确选择，不静默切换。
4. 确认插座、北京时间日期和时间、套餐及预扣上限。实际接好充电线后主动勾选确认，再预约。
5. 只有服务器持久登记后显示“预约已生效”。关闭网页不取消计划，结果回本页查看，并在微信本人订单核对。

扫码入口不含付款身份。完整付款链接不能分享，也不能写进源码、日志或公开配置；网页提交用 HTTPS 请求正文，保存成功后清空输入，服务器不回显授权。旧 Windows 预约不复制到云端，已保存被动冲突提示；它仍由原电脑执行。

## 取消与防重

“同一笔预约只新建一次开电请求”不限制正常重新预约。

- 等待时间、营业恢复或执行前只读核对期间，可取消；取消和提交争用同一行，取消成功会撤销执行租约，旧任务不能继续提交或改回等待状态。
- 取消后可以换插座、重新核对并登记新预约。
- 进入开电提交后，数据库先保存消费标志及原请求，随后才向平台发出唯一一次新请求。提交超时、丢失响应或服务重启后，只核对原请求与本人订单，不盲目新建。
- 结果不明时保留限制。本人在微信查明、处理当前订单，并由服务器确认无本人当前订单后，才能解除后续预约限制；旧请求始终不重发。
- 取消晨充预约不会停止已经启动的尼普顿充电订单。

## 权限与验证

三个业务表启用 RLS，客户端角色没有直接读写权限；私有 RPC 仅供服务端。每次用户操作都向 Supabase 验证身份，并校验实际会话；不信任请求中的用户编号或 `user_metadata`。换账号时清空表单，并在发出请求前核对会话归属，防止旧表单发给新账号。

前端仅包含 publishable key。Vercel 服务凭据保存为 Production Secret；付款配置和冻结请求通过 Vault 主密钥加密。自动 RLS 触发器撤销公开调用权限；安全检查无 WARN/ERROR，三个“RLS 无客户端策略”INFO 是私有表的预期设计。

验证记录：40 项原离线检查、1 项 SDK 换账号传输检查、类型与构建通过；新云端通过 27 项实际接口/权限/持久化检查，以及一次取消与提交的并发竞争检查。测试用户与预约已清理。本人真实付款链接只读验证通过，未创建真实充电、未发真实邮件。此前 41 项 Windows 兼容离线检查通过。

浏览器推送尚未实现，不能声称关闭网页后已有手机提醒。免费平台及默认邮件服务有使用限制；这些检查不等于秒级准点、持续可用性或现场扣款验收。[Supabase Cron](https://supabase.com/docs/guides/cron)、[Vercel Functions](https://vercel.com/docs/functions)。
