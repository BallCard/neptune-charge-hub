# 数据留在本机的边界

当前 Android 本机助手执行，Vercel 仅分发网页和 APK。浏览器可以识别二维码，不能导入凭据、登记真实预约或锁屏开电。iPhone 独立执行未接入，先做[公共只读验证](iphone-shortcuts-validation.md)。

| 内容 | 保存与处理 |
| --- | --- |
| 二维码图片 | 本机 Canvas/jsQR 解码，不上传、不永久保留；仅取设备、端口和区域 |
| 付款链接 | 首次本机解析，仅存账号必需字段；成功清空输入 |
| 账号、SMTP、预约快照与结果 | Android私有目录 AtomicFile，AES-256-GCM、随机IV与认证附加数据；Keystore密钥 |
| 网页与图标 | APK内置；浏览器离线缓存仅程序和静态图片，不缓存账户请求 |
| 配置备份 | 用户选文件目录，PBKDF2-SHA256 310000轮、随机盐、AES-256-GCM；仅账号与邮件配置 |
| 旧网页数据 | 原浏览器 IndexedDB 保留，当前版本不读取、不迁移旧计划 |

关闭应用后无需输入密码，Keystore由系统保护，供后台执行。系统解锁及后台行为需实机核验。本版不提供闲置锁定，持有已解锁手机的人可以看到记录和设置，请用系统锁屏。应用 `allowBackup=false`，不主动同步；系统迁移、root设备或用户将备份存入云盘不由此保证，导出应选本机目录。

恢复需原备份密码和空配置空间；不登记闹钟、不复用冻结订单、不自动开电。卸载通常移除私有数据和密钥，备份密码无法找回。旧浏览器与安卓备份格式不同，不能直接恢复。

安卓使用内置 `https://app.neptune.local/` 页面，本机拦截所有静态请求，阻断其他WebView来源和外部页面。原生代码通过HTTPS直接访问固定 `www.szlzxn.cn/wxn/`，限5个已核对端点、不跟随重定向。

SMTP使用用户指定服务商、TLS465及主机证书核对。邮件含预约时间、设备插座、方案和结果，不含付款身份或授权码。尼普顿和邮件服务商收到完成操作所需的信息；本机存储指开发者网站和数据库不托管凭据或计划，开电仍需联网。

Vercel只分发HTML、JS、CSS、图标及APK，无登录、业务API、数据库、分析上报或第三方网页资源。正常下载会产生托管访问日志；付款链接不进入网站地址或请求正文。构建、Git和发布包不含 `.local/`、用户配置、签名私钥和备份。

预约冻结账号、方案、费率和邮件配置；执行前再核对本人订单、余额、插座及费率。提交前持久化占用，新开电只发一次；丢失响应只能核对，不能重发。保留原token时只继续原请求确认。确认启动要求原请求确认且本人订单匹配插座。

不明结果保留限制。用户核对微信订单与扣款、且官方当前无本人订单后才能新建后续预约；不追认旧订单成功、不重放旧请求。

邮件独立记录，SMTP返回250才显示“已交给邮件服务器”。DATA后响应丢失为邮件结果不明、不重发。明确失败最多3次（备用检查、重启恢复或用户重试）；不因邮件失败重复开电。

定时、后台联网、关机、强制停止和省电需手机核验。依据：[Android准确闹钟](https://developer.android.com/develop/background-work/services/alarms)、[Android14权限变化](https://developer.android.com/about/versions/14/changes/schedule-exact-alarms)。文档不能代替锁屏实测。
